# mebel_site
Сайт визитка с портфолио

## Фотографии портфолио

- Загружаемый файл: JPEG, PNG, WebP, HEIC или HEIF, не более 20 МиБ.
- Максимальный размер исходника: 16 000 px по стороне и 80 мегапикселей.
- Перед постоянным сохранением исправляется EXIF-ориентация, длинная сторона уменьшается до 2560 px.
- Результат сохраняется только в WebP с качеством 82; исходный файл в медиах не сохраняется.
- Для чтения HEIC/HEIF используется `pillow-heif`; при запуске Django проверяет доступность декодера.
- Nginx принимает multipart-запрос до 21 МиБ, оставляя запас для служебных данных формы.
